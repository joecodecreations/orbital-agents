Orbital Agents Browser Controller

Options

Bridge

The bridge on this computer, http://127.0.0.1:<port>. Same as browser.bridge_port in config.toml (default 7703).
ConnectionNot checked yet.
Turn off to pause all agent control of this browser.

Behavior

Each agent session gets its own window, which opens in the background and never takes focus from you.
Automatic uses a second display when there is one.
Records requests, responses and API endpoints from every tab for agents to read. Credentials are redacted by the bridge. Leave off unless you need it.

Getting started

  1. Start the bridge on this computer: orbital browser serve (the setup wizard can install it as a background service).
  2. Leave this extension loaded. The toolbar popup shows connected once it reaches the bridge.
  3. Drive the browser from a terminal or an agent:
orbital browser status
orbital browser navigate https://example.com
orbital browser click "a[href]"
orbital browser type "input[name=q]" "hello" --human
orbital browser screenshot --out page.png
orbital browser --node my-other-mac tabs

Security: the extension only talks to 127.0.0.1. Other machines can reach this browser only when the bridge is started with browser.bind = "tailscale" and they present the bridge token. Anyone who can reach the bridge can act in your logged-in tabs, so keep the token private.
